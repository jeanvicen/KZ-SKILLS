# Roadmap

This roadmap describes sequence, not a promise that every item is already implemented.

## Phase 1 — Foundation (current)

- [x] Establish repository identity and an English landing page.
- [x] Create scalable skill categories and authoring guidance.
- [x] Add a reusable skill template and lightweight validation workflow.
- [x] Document portability and avoid unsupported “works everywhere” claims.

## Phase 2 — First reviewed skills

- [ ] Select a small set of real, high-value workflows across a few categories.
- [ ] Test activation quality, usefulness, and limitations with example tasks.
- [ ] Publish only after review; keep empty categories as structure until needed.

## Phase 3 — Discovery and contributions

- [ ] Decide whether a generated skill catalog is useful once the library grows.
- [ ] Add contribution issue templates and maintainers' review checklist as needed.
- [ ] Document tested installation paths for specific hosts when verified.

## Open decision: license

A license has intentionally not been selected in this scaffold. Before accepting contributions or presenting the collection as reusable open source, the maintainer should choose a license that matches the intended permissions and add the corresponding license file and contribution terms.
