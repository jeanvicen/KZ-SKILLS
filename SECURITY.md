# Security policy

## Reporting a concern

Please do not publish exploit details, secrets, or private data in a public issue. Contact the repository maintainer through a private channel listed on the GitHub profile and include a concise description, affected file or workflow, impact, and safe reproduction steps.

## Scope

Report exposed credentials, unsafe scripts, malicious instructions, privacy concerns, or misleading claims about access and permissions in this repository.

Do not test against systems you do not own or have explicit permission to assess. Security skills in this library must focus on authorized, defensive work.
